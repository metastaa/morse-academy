Morse Academy — Learn Morse Code with an Interactive Visual Schema

Morse Academy is a free, browser-based tool for learning Morse code. Tap the telegraph key to send dots and dashes, watch the visual schema light up the path to each letter, and read the decoded text in real time. No signup, no install — runs on any device.

How to learn Morse code with the schema

The schema is a dichotomic tree: every branch to the left represents a dot (•) and every branch to the right represents a dash (—). Start at the root and follow the signals you send to land on the correct letter. The most common English letters (E, T, A, I, N, M, S, O) sit closest to the root because they have the shortest codes.

Examples

  • E = • (one dot)
  • T = — (one dash)
  • A = •— (dot dash)
  • N = —• (dash dot)
  • SOS = ••• ——— ••• (the international distress signal)
